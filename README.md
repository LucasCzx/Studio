# ✨ Studio Glamourosas

O **Studio Glamourosas** é um projeto de desenvolvimento web criado para representar a identidade de um studio de beleza através de uma interface moderna, elegante e responsiva.

O projeto foi **idealizado e desenvolvido por mim, Lucas**, utilizando **HTML, CSS e JavaScript**, buscando unir estética, usabilidade e uma boa experiência para o usuário.

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript
